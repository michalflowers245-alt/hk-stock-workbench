# 港股工作台｜中文本地版

港股工作台在本机运行，汇总香港银行和券商的公开活动、港交所新股和公开行情快照。活动、任务、教程、资金安排和收益台账保存在当前电脑。

此仓库发布中文本地版源代码。首次启动会创建空的本地数据库，已有账户和财务记录仍在原电脑。

## 打开与关闭

1. 在安装了 Python 3.12 的 Mac 上打开仓库目录，双击 **「打开港股工作台.command」**。也可以在终端执行 `./打开港股工作台.command`。首次运行会安装依赖并打开 [工作台](http://127.0.0.1:8738)。
2. 页面打开后，可以关闭启动时出现的终端窗口；网页与采集器会继续在本机运行。
3. 想停止采集时，双击 **「停止港股工作台.command」** 或执行 `./停止港股工作台.command`。再次打开会恢复运行，原有资料保留。

Mac 睡眠或关机时采集暂停。重新打开后会更新当前公开资料，停机期间缺失的历史不会补造。关闭浏览器页面本身不会停止本机后台；使用停止快捷方式可一起停止网页和采集器。此版不设置开机自动启动，也不依赖其他设备。

## 可以做什么

- **平台活动：** 查看 ZA Bank、WeLab Bank、艾德、FaFa 熊猫证券、辉立的可读取公开活动。保存条款版本和来源状态；App 专属公告可手工录入。显示“检查失败”时保留具体原因及上次成功时间。
- **行情与打新：** 查看无需注册的公开行情快照和港交所新股资料，保留来源及报价、采集时间。快照不标成实时行情；公开来源未返回的标的显示缺失。行情记录可导出 CSV。
- **条件匹配：** 在“我的账户”记录开户情况、受邀情况及预算，再核对活动门槛。缺失条件显示待核实，不把未知判成符合。
- **任务与资金：** 记录登记、入金、达标、留存、领奖、到账任务，保留本人凭证；资金日历检查同时参加活动是否超过预算。
- **教程与复盘：** 根据已收录条款生成本人清单与分享草稿，汇入本人确认可公开的实操心得。无 AI 账号也可使用条款模板。
- **收益台账：** 预计奖励与实际分次到账分别保留，现金、费用、券、交易与汇兑损益分账；券可后续登记使用价值。活动和平台复盘只根据已登记数据计算。
- **工作台提醒：** 活动变更、个人任务与预计奖励到期等提醒保存在页面内查看，不依赖邮件服务。

## 众安、WeLab 和艾德

进入「我的账户」，这三家各有公开活动、录入专属活动和本人账户记录入口。公开活动在本机运行期间定期检查。众安通过可访问的官方公开条款和活动说明覆盖部分活动，主站结果在「本地状态」单独显示。特选或 App 内专属活动以本人收到的通知为准。

「余额、持仓与流水」支持单条录入，以及下载账户记录模板后批量导入 UTF-8 CSV。预览时会检查日期、原币金额和重复流水编号。请按官方 App 或电子结单的资料日期填入，按确认才写入本机。模板是工作台格式，银行原版 PDF 需先整理所需字段。结单入口以各家官方说明为准。 [众安结单](https://bank.za.group/hk/hk/faqs/Individuals/Transfer/Transfer_App_operation/67b5964cccffd730c885c6d2) · [WeLab 结单](https://www.welab.bank/zh-CN/support/bank-account/how-can-i-see-my-estatement/) · [艾德账户支持](https://www.eddid.com.hk/sf/support/)

本人账户记录是本机的历史快照，可按资料日期查询。账户记录和本机数据库备份都包含已录入的个人财务数据，表格只需填写所列字段。流水编号使用结单参考号或自行指定的稳定编号。误录的资料可移除后重新录入。

账户余额、持仓和流水通过手动录入或 CSV 导入维护。自动同步个人银行和券商账户仍待实现，云端部署和账户端到端验收仍待验证。

## 数据与备份

- 业务数据库：`data/workbench.sqlite3`。
- 本机运行日志：`data/local-logs/`。
- 自动备份：运行期间每天备份，启动时也会检查当日备份，保留最近 14 份经过完整性检查的数据库快照，位于 `data/backups/`。备份也在本机，不等于异地备份。
- 已有活动、任务、资格记录和真实台账不因切换本地模式而清空；测试不会写进本人收益。

如需迁移个人记录到另一台电脑，先停止工作台，再通过私下的文件传输复制 `data/`。项目代码仓库适合新建空工作台。

## 遇到问题

先再次双击启动入口。启动器会分别检查网页和采集器；网页仍在而采集器已退出时，会尝试恢复采集器。如果端口被其他程序占用，会停止并提示，不会结束无关进程。

查看“运行状态”中的来源失败原因。网页打不开时，可查看 `data/local-logs/web.log`；活动不更新时查看 `worker.log`。已有资料仍可在本机读取，来源是否恢复以页面显示为准。

## 开发与验证

首次运行后，Python 环境位于 `.venv/`。可以从仓库目录运行：

```bash
.venv/bin/python ops/local_runtime.py start
.venv/bin/python ops/local_runtime.py stop
.venv/bin/python -m unittest discover -s tests
.venv/bin/python -m unittest discover -s ops
```
